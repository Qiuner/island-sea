# 云游 · 东方明珠 —— 陆家嘴 3D 漫游

出发前先"云玩"一遍目的地：操控小旅人在 3D 陆家嘴里自由行走，走进东方明珠、上海中心、金茂大厦、环球金融中心，登上浦江游船，白天黑夜随意切换。

## 怎么打开

1. 双击 `云游·东方明珠.html`，用 **Chrome / Edge / Safari** 打开即可，无需安装任何东西。
2. **首次打开需要联网**（页面会从网上加载 3D 引擎，几秒钟）。之后操作全部在本机进行。
3. 建议用电脑打开体验最佳；手机浏览器打开也能玩（虚拟摇杆操作）。

## 操作方式

### 电脑
| 按键 | 作用 |
|---|---|
| W A S D / 方向键 | 走动 |
| Shift | 跑 |
| 空格 | 跳 |
| 鼠标按住拖动 | 转视角 |
| 滚轮 | 拉近 / 拉远 |
| Esc | 从建筑里返回地面 |

### 手机
- 左半屏拖动 = 走动，右半屏拖动 = 转视角，右下角圆形按钮 = 跳

## 玩法

- **走进地面上发光的光环**，就能进入对应建筑：
  - 东方明珠 → 263 米上球体观光层（有一段悬空玻璃地板，敢不敢往下看？）
  - 上海中心 → 546 米"上海之巅"观光厅
  - 金茂大厦 → 88 层空中中庭（可以站在玻璃上看向下的无限天井）
  - 环球金融中心 → 474 米玻璃观光天桥
  - 浦江游船 → 码头栈桥尽头登船
- 建筑里走进**金色光环**（或按 Esc）返回地面。
- 右上角 **🌙 看夜景** 一键切换黄昏/夜晚，夜里东方明珠会亮起粉色 LED。
- 底部一排按钮可直接传送到各景点，并弹出该景点的介绍卡（亮点 + 游玩 TIPS）。

## 遇到问题

- **打开是白屏/一直转圈**：先确认联网，然后刷新一次（Cmd/Ctrl + R）。
- **提示"打不开 3D 世界"**：说明该设备/浏览器不支持 WebGL，换台电脑或换 Chrome 试试。
- **画面卡顿**：关掉浏览器其他标签页；或换性能好一点的设备。
