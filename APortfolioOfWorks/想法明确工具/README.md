# Idea Pilot

把模糊的项目想法逐步收敛为可验证的 MVP，并生成可直接交给 AI 编程工具的开发提示词。

## 直接启动（macOS）

在 Finder 中双击根目录的 `想法明确工具.app`。首次启动会自动检查 Node.js 和项目组件，随后会明确打开终端并用默认浏览器访问工具网址。

使用期间请保持弹出的终端窗口打开；关闭该窗口即停止本地服务。若 3000 端口已被占用，启动器会自动改用 3001 端口。若浏览器没有自动弹出，终端窗口会显示可手动访问的网址。

启动器会把运行日志放在 `.local-run/server.log`，这个文件夹可在排查问题时查看，无须手动处理。

## 首次配置 DeepSeek

在根目录的 `.dev.vars` 文件里填入你的 DeepSeek API Key。具体步骤见 [DeepSeek API Key 配置](docs/DeepSeek%20API%20Key%20配置.md)。修改配置后，关闭启动窗口，再重新双击启动器。

## 开发者启动方式

```bash
npm run dev
```

## 项目文件说明

- `想法明确工具.app`：日常双击启动入口。
- `启动「想法明确工具」.command`：App 使用的启动脚本；也可以直接双击它启动。
- `app/`：页面与 API 代码。
- `docs/`：配置说明和技术方案。
- `.dev.vars`：你的 API Key 配置（私密文件，不会被提交）。
- `dist/`、`.vinext/`、`.wrangler/`、`.local-run/`：自动生成的构建、运行或日志文件，无须手动编辑。

## 可选的开发命令

- `npm run build`：构建检查。
- `npm test`：构建并运行页面测试。
